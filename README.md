# Тестовое задание: Автоматизация сборки и деплоя (Python/Docker/Ansible)

Данный репозиторий содержит выполнение трехэтапного задания по автоматизации работы с HTTP-запросами, контейнеризации приложения и оркестрации процесса с помощью Ansible.

## Структура проекта

- `section1/`: Python-скрипт для проверки HTTP-статусов.
- `section2/`: Контейнеризация скрипта на базе Ubuntu 22.04.
- `section3/`: Ansible-плейбук для автоматизации установки Docker и запуска контейнера.
