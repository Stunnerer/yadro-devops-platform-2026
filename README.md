# Тестовое задание: Автоматизация сборки и деплоя (Python/Docker/Ansible)

Данный репозиторий содержит выполнение трехэтапного задания по автоматизации работы с HTTP-запросами, контейнеризации приложения и оркестрации процесса с помощью Ansible.

## Структура проекта

- `section1/`: Python-скрипт для проверки HTTP-статусов.
- `section2/`: Контейнеризация скрипта на базе Ubuntu 22.04.
- `section3/`: Ansible-плейбук для автоматизации установки Docker и запуска контейнера.

## Ключевые технические решения

1. **Стандартная библиотека Python:** Скрипт реализован на `http.client` без внешних зависимостей (requests), что минимизирует размер Docker-образа и упрощает поддержку.
2. **Безопасность:** В Docker-образе создан и используется непривилегированный пользователь `appuser`.
3. **Надежность Ansible:** Для управления сессиями после изменения групп пользователя применен `meta: reset_connection`, что предотвращает ошибки прав доступа в рамках одного запуска.
4. **Универсальность:** Код протестирован на `httpbin.org` в связи с нестабильностью `httpstat.us`.

## Быстрый старт (Ansible)

Если у вас установлен Ansible, вы можете запустить весь цикл (установка + проверка) одной командой:

```bash
cd section3
ansible-galaxy install -r requirements.yml
ansible-playbook playbook.yml -K
```
