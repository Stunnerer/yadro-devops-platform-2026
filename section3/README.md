# Раздел 3: Автоматизация с Ansible

## Описание

Плейбук автоматизирует полный цикл подготовки хоста и запуска приложения.

- **Роли:** Используется проверенная роль `geerlingguy.docker` для установки Docker.
- **Действия:**
  1. Установка Docker и зависимостей.
  2. Добавление пользователя в группу `docker`.
  3. Сборка образа из исходников.
  4. Запуск контейнера и вывод логов в консоль Ansible.

## Подготовка

Перед запуском необходимо установить зависимости (роль Docker):

```bash
ansible-galaxy install -r section3/requirements.yml
```

## Запуск

Для запуска на локальной машине (localhost):

```bash
cd section3
ansible-playbook playbook.yml -K
```
