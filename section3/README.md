# Раздел 3: Автоматизация с Ansible

## Описание

Автоматизация настройки инфраструктуры "с нуля" до рабочего приложения.

### Состав плейбука

1. **Установка Docker:** Используется роль `geerlingguy.docker`, являющаяся стандартом для этой задачи.
2. **Управление доступом:** текущий пользователь добавляется в группу `docker`. Для немедленного обновления прав используется `reset_connection`, чтобы не требовалось повторное подключение.
   *Примечание: при локальном запуске нужно вручную заново войти в учетную запись, так как `reset_connection` не работает с локальным соединением.*
3. **Жизненный цикл контейнера:**
   - Копирование исходного кода во временную директорию `/tmp`.
   - Сборка образа (идемпотентно).
   - Запуск контейнера в режиме `detach: false` для прямого получения логов и кода возврата.

## Запуск

```bash
# 1. Установка внешней роли
ansible-galaxy install -r requirements.yml

# 2. Запуск плейбука
# Флаг -K (ask-become-pass) нужен для установки Docker через sudo
ansible-playbook playbook.yml -K
```
