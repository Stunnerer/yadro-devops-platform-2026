# Раздел 2: Работа с Docker

## Описание

Создан Docker-образ на базе официального образа `ubuntu:22.04`.

- **Особенности:** В образ включен пакет `ca-certificates` для корректной работы SSL/HTTPS запросов.
- **Зависимости:** Установлен `python3`, дополнительные библиотеки не требуются (используется стандартная библиотека).
- **Безопасность:** Контейнер не использует права root при выполнении скрипта, что соответствует правилам безопасности.

## Сборка и запуск

1. Сборка образа:

   ```bash
   docker build -t http-checker section2/
   ```

2. Запуск контейнера:

   ```bash
   docker run --name checker-instance http-checker
   ```

3. Проверка логов:

   ```bash
   docker logs checker-instance
   ```
