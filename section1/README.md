# Раздел 1: Работа со скриптом

## Описание

Скрипт (`script.py`) выполняет 5 запросов к сервису.

### Особенности реализации

- **Exception Handling:** Скрипт генерирует `http.client.HTTPException` при получении статус-кодов 4xx и 5xx. Ошибки перехватываются в цикле, чтобы один неудачный запрос не прерывал выполнение всей программы.
- **Логирование:** Используется стандартный модуль `logging`. Выводятся статус-код, фраза ответа, заголовки и тело ответа.
- **Zero-dependency:** Используются только встроенные модули Python 3.10+.

## Запуск

```bash
python3 section1/script.py
```
