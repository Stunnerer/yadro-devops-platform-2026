# Раздел 1: Работа со скриптом

## Описание

Скрипт (`script.py`) выполняет 5 запросов к сервису.

- **Сервис:** Использован `https://httpbin.org` вместо `httpstat.us` в связи с нестабильной доступностью последнего.
- **Логика:**
  - Коды 1xx, 2xx, 3xx логируются как успешные (вывод кода, описания и заголовков).
  - Коды 4xx, 5xx вызывают исключение `http.client.HTTPException`.
  - Все ошибки обрабатываются в блоке `try-except` для обеспечения выполнения всех 5 запросов.

## Запуск

```bash
python3 section1/script.py
```
